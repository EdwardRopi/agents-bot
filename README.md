# agents-bot

Telegram Mini App: команда ИИ-агентов для малого бизнеса.
Клиент рассказывает о своём деле один раз, дальше ставит задачи агентам.

## Как это работает сейчас

Ключа к API пока нет, поэтому сервис работает **гибридом**:

```
клиент в мини-аппе → задача в очередь → уведомление владельцу
                                              ↓
                          Claude Code на машине владельца:
                          скила agent-inbox, агенты smm/editor/leads
                                              ↓
              результат обратно в сервис → клиент получает уведомление
```

Для клиента это выглядит как работающий сервис. Когда появится ключ, вместо
ручного прогона встанет серверный воркер, дёргающий те же эндпоинты `/runner` —
**мини-апп при этом не меняется вообще**.

## Запуск

```bash
npm install
cp .env.example .env      # заполнить
npm run migrate           # создать таблицы
npm run dev               # сервер + бот
```

Фронт собирается отдельно в `web/` и отдаётся тем же сервером из `web/dist`.

## Что где

| Файл | Зачем |
|---|---|
| `src/agents.js` | витрина команды: имена, роли, примеры задач. Должностных инструкций тут нет и быть не должно |
| `src/brief-schema.js` | 11 разделов брифа. Фронт рисует мастер по этому описанию — новый вопрос добавляется правкой одного файла |
| `src/routes/tasks.js` | постановка задач. Не пускает, пока не заполнен бриф, и не даёт ставить вторую задачу одному агенту |
| `src/routes/runner.js` | мост к локальной машине: забрать очередь, вернуть результат |
| `src/utils/validateInitData.js` | проверка подписи Telegram. Без неё любой может прислать запрос от чужого имени |
| `tools/inbox.js` | клиент раннера: `list`, `show`, `claim`, `result`, `fail` |

## Безопасность

- `.env` в git не попадает. Токен бота, доступ к базе и `RUNNER_TOKEN` —
  только там.
- `/runner` защищён отдельным секретом и не имеет ничего общего с сессией
  пользователя: даже если клиент подделает запрос, до очереди он не дотянется.
- Инструкции агентов клиенту не отдаются ни через один эндпоинт. Это то,
  что нельзя повторить, посмотрев на результат.
